# Soma Sekhara Reddy | Data Analyst Portfolio

Professional static portfolio website for Data Analyst, Power BI, SQL, Python and GenAI projects.

## Included
- Responsive portfolio homepage
- About, skills, experience and contact sections
- Resume download
- LinkedIn and GitHub buttons
- Swiggy, PhonePe and MS Dhoni IPL project screenshots
- GitHub links for each project

## Run locally
Open `index.html` in Chrome, Edge or any modern browser.

## Publish on GitHub Pages
Upload all files and folders to your repository. Then go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
